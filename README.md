## Overview

NadIR is a free dual-channel cabinet IR loader with a built-in library of guitar and bass cab IRs, phase alignment, and a stereo field width control for professional guitar recording without physical cabs.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Ignite Amps NadIR** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Dual Channel** | Load two independent IR files for stereo cab simulation |
| **IR Library** | Built-in impulse response library covering classic guitar cabinets |
| **Phase Alignment** | Automatic or manual phase alignment between dual channels |
| **Stereo Width** | Independently pan and mix the two channels for stereo spread |
